# MedScale public qualification gates

MedScale is a free, local-first open-source Beta project with real, user-approved local Whisper transcription for nonpatient recordings and synthetic health-workspace fixtures. Public installer cutover, real patient record handling and clinical deployment remain separate qualification decisions. This page documents material boundaries and evidence without treating engineering tests as medical certification.

## Verified AudioFlow scope

- **Windows real end-to-end desktop:** a user-driven import, actual nonfixture Whisper transcription and restart on licensed human LibriSpeech audio passed [dedicated GitHub Actions](https://github.com/AbdulazizShehri/MedScale/actions/runs/40209018576). Latest AudioFlow integration [PR #328](https://github.com/AbdulazizShehri/MedScale/pull/328) merged into `main` after exact-head Rust, native Tauri, desktop E2E and browser smoke passed.
- **macOS first-run native real-human Audio GUI:** a disposable macOS runner [#40687382970](https://github.com/AbdulazizShehri/MedScale/actions/runs/40687382970) exercised the actual WKWebView app: checked available storage, verified the download button remained disabled until explicit user consent, acquired and activated the pinned Whisper Tiny English Pack through the production UI, imported a verified CC-BY-4.0 LibriSpeech WAV, and displayed a nonfixture local transcription. The native journey **PASSED**; [PR #350](https://github.com/AbdulazizShehri/MedScale/pull/350) subsequently merged into protected main at `f2a64ecba0ddd3abcee4b6e95038a51bf994add3` after Rust 6/6 and Tauri 3/3. This first-run acceptance alone did not qualify OS file pickers, failure recovery, VoiceOver, notarization, or all end-user Apple hardware; **separate, narrower native checks** below now qualify specific picker and controlled-failure behaviors.
- **Actual macOS file/folder chooser cancellation:** [PR #356](https://github.com/AbdulazizShehri/MedScale/pull/356) was merged into protected main after [native macOS qualification #40804095510](https://github.com/AbdulazizShehri/MedScale/actions/runs/40804095510) **PASS**. The disposable WKWebView app opened real AppKit WAV and folder selectors; PID-targeted OS Escape closed both, retained the exact previously entered paths, and recovered enabled controls. The folder dialog required two Escape keys. This is evidence for **cancel-and-restore of two native pickers on hosted macOS**, not proof of production user-device TCC permissions, full keyboard navigation, VoiceOver, or file import from an arbitrary customer filesystem.
- **Controlled macOS model network-error recovery:** [PR #357](https://github.com/AbdulazizShehri/MedScale/pull/357) merged after [native macOS qualification #40827463514](https://github.com/AbdulazizShehri/MedScale/actions/runs/40827463514) **PASS**. The disposable CI checkout injected an early zero-HTTP fault into the real native model downloader: no-consent gating, sanitized offline error, verified absence of installed Pack, cleanup of a populated app-owned temporary stage while preserving an unrelated file, and fresh consent required for retry all passed through WKWebView. No model bytes or actual OS-wide network outage occurred. This does **not** establish real Wi-Fi-loss/DNS failure recovery on end-user devices.
- **Real source-bound models:** pinned Whisper Tiny English, Tiny Multilingual, Base Multilingual and Small Multilingual passed [download/hash/signed-Pack qualification](https://github.com/AbdulazizShehri/MedScale/actions/runs/40216374598) on ephemeral macOS CI. Model weights are not in the desktop installer.
- **Actual English benchmark:** on 100 licensed LibriSpeech test-clean excerpts (40 speakers, 707.7 seconds), Whisper Tiny English's measured corpus WER was **5.58%** in an independent [real-data evaluation job](https://github.com/AbdulazizShehri/MedScale/actions/runs/40114179864).
- **Actual Arabic benchmark:** on 24 FLEURS `ar_eg` read-speech excerpts (298 seconds), corpus WER was **65.28% Tiny**, **46.15% Base**, **25.78% Small** (separately evaluated on the MedScale ASR runtime: [Tiny](https://github.com/AbdulazizShehri/MedScale/actions/runs/40118126000), [Base](https://github.com/AbdulazizShehri/MedScale/actions/runs/40118134257), [Small](https://github.com/AbdulazizShehri/MedScale/actions/runs/40119541369)). The dataset is Egyptian Arabic read speech, not a measurement of all Arabic accents.
- **Expanded Arabic benchmark (100 excerpts, 1,154.26 seconds, exact same FLEURS `ar_eg` cohort):** MedScale's pinned multilingual Whisper runtimes measured **Tiny WER 65.22%, CER 25.19%, CPU RTF 0.129×** ([run](https://github.com/AbdulazizShehri/MedScale/actions/runs/40670602204)); **Base WER 47.11%, CER 16.08%, CPU RTF 0.397×** ([run](https://github.com/AbdulazizShehri/MedScale/actions/runs/40673995965)); and **Small WER 28.90%, CER 8.97%, CPU RTF 0.828×** ([run](https://github.com/AbdulazizShehri/MedScale/actions/runs/40674446821)). The reference contains **1,889 whitespace-delimited words and 9,119 normalized characters excluding spaces**. Word/character rates use a Unicode alphanumeric normalization with Arabic harakat stripped; they are not comparable without matching normalizers. The pinned source test parquet has **no `speaker_id` column**, so **speaker diversity and the max-four-per-speaker limit are not verified** for these 100 samples. CPU times are hosted-runner measurements, not customer hardware targets. These are read-speech benchmarks, not clinical ASR accuracy, and no default-model promotion is implied.
- **Private installer candidate:** Windows x64 and macOS ARM64 unsigned packages sourced from the same tree as merged `main@75cef1f` passed native installer checks, independent full manifest and SHA256SUMS verification. See [Beta QA issue #302](https://github.com/AbdulazizShehri/MedScale/issues/302). No new public installer, website cutover, model weights or GitHub Release was published.

These measured results are specific to public read-speech material and those CI environments. The bounded native macOS real-speech first-run path, two native picker cancellation/path-retention paths, and controlled no-HTTP error cleanup path have separate passing hosted-runner evidence above. **Still unqualified:** VoiceOver and comprehensive accessibility, production OS privacy/TCC prompts, physical disk or network outage recovery, customer hardware, production signing/notarization, clinical performance and patient-data authorization. Passing a hosted CI test does not make the entire platform or release ready.

## Interpreting engineering evidence

Historical Spec 072 engineering coverage, **including Models/Evidence**, documents available test work; it does not satisfy the external qualifications above or certify a product. Individual CI successes cannot close clinical, privacy, performance or signing gates.

Use the [public project documentation](../../README.md), [security policy](../../SECURITY.md) and [source provenance](../../third_party/provenance/) for reviewable technical details. Report security vulnerabilities privately through the [security policy](../../SECURITY.md), not in public issues.

Maintainer-specific execution schedules, workstation incidents, provider accounts, unpublished strategy, and internal decisions are deliberately not published here. This file is not a release checklist approval. No GitHub Release is authorized by its contents.
