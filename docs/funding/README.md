# MedScale — open-source funding and grant workspace

_Last reviewed: 2026-11-02 (Asia/Riyadh). This is a planning and application-preparation workspace. No applications or awards are implied by inclusion here._

## What is being funded

MedScale is an Apache-2.0, free, local-first, open-source health intelligence desktop project. It has a Rust core, Tauri/React desktop, evidence provenance, locally protected workspaces, bounded FHIR R4 interchange and user-consented, local Whisper transcription. Source: [README](../../README.md) and [qualification gates](../qualification/EXTERNAL_GATES.md).

**Safety and claims boundary:** MedScale is an engineering Beta, not clinically validated or approved for real patient records. Applications must not claim clinical safety, healthcare deployment, regulatory approval, production-ready PHI security, adoption metrics, revenue, legal entity registration or research affiliations that cannot be evidenced. AI evaluations use synthetic health records, public/licensed nonpatient data and audited public benchmarks only. No patient data, provider credentials, private partner endpoints, model weights or restricted assets are uploaded in funding workflows.

## Submission integrity

No programme should be marked `submitted` without a receipt (confirmation email, application ID or screenshot). No award should be described as received without a provider confirmation. Use the project's official email *only when the maintainer verifies it and the sending account*. Do not commit personal phone/address, identity documents, payment/tax details, API keys, project credentials or nonpublic partner material.

This folder is public documentation in a public repository; drafts are not secret, do not constitute contractual promises, and should be reviewed against live program terms immediately before submission.
