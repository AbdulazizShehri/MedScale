## Suggested public profile description

MedScale is an independent Apache-2.0 open-source desktop project that explores transparent evidence provenance, locally protected workspaces, bounded FHIR interoperability, and reproducible nonclinical AI evaluation. We aim to make trustworthy health-information tooling easier to inspect, understand, and improve without requiring a cloud account.

MedScale is currently an engineering Beta. It is not clinically validated and not authorized to process real patient information. Your sponsorship supports open-source maintenance, cross-platform tests, security and accessibility work, documentation, and public research using synthetic or licensed nonpatient data.

We publish engineering evidence and limitations rather than overstating real-world medical readiness. Funding supports the project and its maintenance; **sponsorship does not purchase clinical advice, healthcare services, private patient-data processing, priority access to unpublished medical functionality, or a guaranteed delivery date.**

Project source: https://github.com/AbdulazizShehri/MedScale
