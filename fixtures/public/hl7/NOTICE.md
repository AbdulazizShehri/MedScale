# Public HL7 FHIR examples

Unmodified example files published by HL7 International in its FHIR implementation guides. They describe fictional people. HL7 publishes FHIR specification content, including these examples, under CC0 (public domain dedication); see https://hl7.org/fhir/R4/license.html. FHIR® is a registered trademark of HL7.

They test MedScale's FHIR import against real-world shapes (B2 in `docs/beta/REAL_DATA_READINESS.md`). Like every fixture, they are not patient data. The US Core Patient example carries a fictional US SSN-style identifier, so the unencrypted sample workspace refuses to import it, by design.
